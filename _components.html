JS utilities
Available on every page via window.FlexUtil from flex-platform.js.
FlexUtil.pad(n)            // "07"
FlexUtil.ymd(date)         // "2026-04-30"
FlexUtil.ymdhm(date)       // "2026-04-30 09:30"
FlexUtil.dmy(date)         // "30/04/2026"
FlexUtil.nzOffset(date)    // "+12:00" or "+13:00"
FlexUtil.fmtNum(1234567)   // "1,234,567"
FlexUtil.round3(1.23456)   // 1.235
FlexUtil.fmtKwh(1.23456)   // "1.235"
FlexUtil.escapeHtml(str)   // safe for innerHTML
FlexUtil.seedRng(seed)     // returns a deterministic rand()
